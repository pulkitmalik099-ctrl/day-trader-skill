1. Chart Scanner

          
Scans thousands of charts for Opening Range Breakouts (ORB) and flags

        

        trader-scanner/scan.py
      

      

        Parses symbol universes, historical bars, and identifies stocks breaking above their opening ranges. Supports NIFTY 500 equities for India and US equities via Nasdaq Trader symbol lists.
      


      

        

          Indian Market (NIFTY 500)
          
        

        # Fetch universe & scan Indian Opening Range Breakouts
python trader-scanner/scan.py universe --market IN
python trader-scanner/scan.py orb --market IN --at 10:15
      


      

        
ReadsWrites

        
EQUITY_L.csv or Nasdaq SymDirtrader/universe.txt, trader/watchlist.json

      

    


    
    

      

        

          
2. News Monitor

          
Tracks breaking headlines, SEC 8-K filings, and Indian regulatory moves

        

        trader-news/news.py
      

      

        Cross-checks breaking headlines with day move percentages. Automatically tags Indian market context (SEBI, RBI, FII/DII institutional flows, Promoters, NIFTY) and resolves `.NS`/`.BO` tickers.
      


      

        

          Command
          
        

        python trader-news/news.py --tickers RELIANCE.NS TCS.NS --market IN
      

    


    
    

      

        

          
3. Entry Timer

          
Watches setup bar-by-bar and confirms entries on closed candles

        

        trader-entry/entry.py
      

      

        Monitors 5-minute and 1-minute bars. Triggers only when a candle CLOSES past the level, preventing intraday false spikes.
      


      

        

          Command
          
        

        python trader-entry/entry.py check RELIANCE.NS --market IN --write

09:15 IST (India)09:30 to 15:15 ISTtrader/entry.json

      

    


    
    

      

        

          
4. Exit Planner

          
Pre-determines stop loss, profit target, and mandatory intraday flat-by time

        

        trader-exit/exit.py
      

      

        Enforces discipline: both exit points are set before order entry. Automatically enforces the 15:25 IST (India) or 15:55 ET (US) flat-by rule so no position is held overnight.
      


      

        

          Command
          
        

        python trader-exit/exit.py plan --market IN --symbol RELIANCE.NS --entry 2500 --stop price:2475 --target price:2550 --write
      

    


    
    

      

        

          
5. Time Machine Replay

          
10,000 Monte Carlo replays plus historical setup evaluations

        

        trader-timemachine/timemachine.py
      

      

        Simulates the remainder of the session using the stock's actual last 60 days of 5-minute candles (75 bars in Indian session, 78 bars in US session) to calculate hit odds before risking any capital.
      


      

        

          Command
          
        

        python trader-timemachine/timemachine.py run --market IN --replays 10000 --write
      

    


    
    

      

        

          
6. Budget Manager

          
Mathematical position sizing capped strictly by your maximum loss rule

        

        trader-budget/size.py
      

      

        Converts the trade plan into an exact share quantity. The stop distance dictates the size: wider stop equals smaller position. Supports INR (`config.example.india.json`) and USD sizing.
      


      

        

          Command
          
        

        python trader-budget/size.py --market IN --write
      

    


    
    

      

        

          
7. Risk Manager

          
Independent veto checks: circuit filters, daily loss limits, and entry windows

        

        trader-risk/check.py
      

      

        Strict PASS or BLOCK gatekeeper. In Indian market mode, evaluates exchange circuit bands (5%, 10%, 20%) to ensure orders cannot be trapped in limit halts.
      


      

        

          Command
          
        

        python trader-risk/check.py --market IN
      

    


    
    

      

        

          
8. Order Executor

          
Plain-English ticket rendering for Zerodha Kite Connect & Alpaca paper trading

        

        trader-broker/ticket.py
      

      

        Nothing goes through without explicit user approval. Renders clean, clear tickets in INR (₹) or USD ($) ready for manual confirmation or API transmission.
      


      

        

          Command
          
        

        python trader-broker/ticket.py show --market IN
      

    


    
    

      

        

          
9. Price Alerts & Clock

          
Market clocks, stop alerts, target rings, and end-of-day flatten bells

        

        trader-alerts/alerts.py
      

      

        Manages NSE/BSE and NYSE market calendars, 2026 trading holidays, and sounds alerts when stops, targets, or close approaching times are reached.
      


      

        

          Command
          
        

        python trader-alerts/alerts.py clock --market IN
python trader-alerts/alerts.py add --from-plan
      

    


    
    

      

        

          
10. Earnings Analyst

          
Quarterly financial facts, margin trends, and cross-listed ADR mapping

        

        trader-analyst/facts.py
      

      

        Extracts verified XBRL facts and cross-references Indian dual-listed ADRs (e.g. INFY.NS to INFY, HDFCBANK.NS to HDB) to extract audited quarterly statements.
      


      

        

          Command
          
        

        python trader-analyst/facts.py INFY.NS
      

    


    
    

      

        

          
11. Insider & Bulk Deals Tracker

          
SEBI PIT Reg 7(2) insider trades, NSE/BSE bulk deals, and Congressional PTRs

        

        trader-pelosi/insider.py
      

      

        Tracks institutional and promoter activities. For India: monitors SEBI Prohibition of Insider Trading disclosures and exchange bulk/block deals. For US: monitors Congressional PTRs.
      


      

        

          Command
          
        

        # Track Indian Promoter & Insider Trading (SEBI PIT)
python trader-pelosi/insider.py pit --promoter-only

# Track NSE / BSE Bulk & Block Deals
python trader-pelosi/insider.py deals
